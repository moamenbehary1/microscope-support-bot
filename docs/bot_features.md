## القسم الأول: الفيتشرز الموجودة حالياً

---

### 👨‍🎓 للطلاب (Student Role)

| الفيتشر | الوصف |
|---|---|
| **تصفح المواد والمحتوى** | الطالب يتصفح: القسم ← المادة ← الفئة (شروحات / ملخصات / ...) ← الملف، مع pagination 5×5 في كل مستوى |
| **تحميل الملفات** | عرض وتحميل ملفات PDF، فيديو، صوت، روابط مباشرة من الفايربيز |
| **البحث الذكي** | بحث بالاسم عبر كل مواد البوت بغض النظر عن القسم |
| **الاشتراك في المواد** | الاشتراك في مادة لاستقبال إشعارات كلما اتضاف محتوى جديد |
| **جداول الدراسة** | التسجيل في جداول الدراسة الجماعية (Study Tables) |
| **التواصل مع الأدمن** | إرسال رسائل مباشرة للأدمن عن طريق Inbox |
| **طلب انضمام** | إرسال طلب انضمام لتيم المساهمين بانتظار موافقة الأدمن |

---

### 🤝 للمساهمين (Contributor Role)

| الفيتشر | الوصف |
|---|---|
| **رفع الملفات** | رفع محتوى جديد (PDF / فيديو / صوت / رابط) لأي قسم ومادة وفئة، مع pagination 5×5 في اختيار المسار |
| **الإضافة السريعة** | `Quick Add` لرفع ملف لنفس المسار الأخير بخطوات أقل |
| **إدارة ملفاتي** | عرض وحذف الملفات اللي المساهم رفعها هو بالذات، مع pagination كاملة |
| **تعديل الملفات (Edit Flow)** | إعادة تسمية / حذف / نقل أي ملف **بعد التحقق من كود الصلاحية ذي المرات والمدة المحدودة** |
| **إحصائياتي** | مشاهدة عدد الملفات المرفوعة وإحصائيات النشاط الشخصي |
| **كود الصلاحية** | إدخال الكود المؤقت الصادر من الأدمن للحصول على صلاحية التعديل؛ الكود يُستهلك عند الاستخدام |

---

### 🛠️ للأدمن (Admin Role)

| الفيتشر | الوصف |
|---|---|
| **لوحة التحكم الكاملة** | Dashboard مركزي لكل عمليات الإدارة |
| **إدارة الأقسام والمواد** | إضافة / حذف أقسام (Tracks) ومواد (Subjects) مع pagination 5×5 |
| **إدارة المساهمين** | عرض قائمة المساهمين، قبول / رفض طلبات الانضمام |
| **مولّد كود الصلاحية** | توليد كود 6 أرقام عشوائي قابل للضبط بـ: **عدد مرات الاستخدام** + **مدة الصلاحية بالدقائق** — presets جاهزة + إعداد مخصص؛ يُلغى تلقائياً عند انتهاء الشرطين |
| **إلغاء الكود (Revoke)** | إلغاء الكود الحالي فوراً قبل انتهاء مدته |
| **تعديل الملفات (Admin Direct)** | إعادة تسمية / حذف / نقل أي ملف **مباشرةً بدون كود** |
| **البث الجماعي (Broadcast)** | إرسال رسالة لكل مستخدمي البوت |
| **إحصائيات البوت** | عرض إجمالي الملفات، المستخدمين، المساهمين |
| **نظام الصلاحيات (RBAC)** | كل أكشن محمي بطبقة تحقق من الرول (Student / Contributor / Admin / Super Admin) |

---

### 👑 للسوبر أدمن (Super Admin Role)

| الفيتشر | الوصف |
|---|---|
| **كل صلاحيات الأدمن** | جميع ما سبق بالكامل |
| **نقل الملكية** | نقل صلاحية Super Admin لمستخدم آخر |
| **ترقية / تخفيض الأدمن** | تغيير رول أي مستخدم بين Admin ↔ Contributor ↔ Student |

---

### ⚙️ مميزات تقنية عامة

| الميزة | التفاصيل |
|---|---|
| **Pagination 5×5 عالمي** | كل القوائم في كل الرولات تعرض 5 عناصر لكل صفحة مع أزرار `⬅️ السابق` / `التالي ➡️` وعداد `📄 X/Y` |
| **Firebase Realtime DB** | تخزين كل المحتوى، المستخدمين، الأكواد في Firebase |
| **Callback byte safety** | كل callback data ≤ 64 bytes باستخدام `Utils.shorten` / `Utils.lengthen` |
| **نظام المهام (Missions)** | تعيين مهام للجان HR وعرضها في البوابة الإلكترونية |
| **بوابة الويب** | `team.html` — صفحة تيم ميكروسكوب بألوان `#102250` / `#1e40af` / `#00d2ff` |
| **بوابة HR** | `hr.html` — نظام تقييم داخلي منفصل للتيم |

## القسم الثاني: الفيتشرز المقترحة للتحديثات القادمة

---

### 📚 1. الجانب الأكاديمي والمذاكرة (Academic & Study Hub)

| # | الفيتشر | الوصف |
|---|---|---|
| 1 | **مسارات التعلم** | خريطة خطوة بخطوة تُرشد الطالب لطريقة مذاكرة كل مادة — أي موضوع يبدأ به، أي كتاب يستخدم، وإزاي يربط المعلومات ببعض |
| 2 | **نظام شريك المذاكرة** | ربط الطلاب ببعضهم للمذاكرة التعاونية — الطالب يحدد المادة والوقت المناسب، والبوت يوصله بزميل متاح للمذاكرة |
| 3 | **مولّد جداول المراجعة** | تقسيم المنهج تلقائياً على الأيام المتبقية قبل الامتحان — الطالب يدخل تاريخ الامتحان وعدد الموضوعات والبوت يولد الجدول |
| 4 | **بنك الخرائط الذهنية** | تجميعة منظمة من الصور والملخصات البصرية السريعة لكل مادة، مثالية لمراجعة ليلة الامتحان |
| 5 | **خريطة المتطلبات الأكاديمية** | توضيح المواد المعتمدة على بعضها (Prerequisites) لتسهيل تسجيل المواد وتخطيط الترمات |

---

### 🛠️ 2. أدوات وخدمات الدفعة (Student Tools & Services)

| # | الفيتشر | الوصف |
|---|---|---|
| 1 | **صانع ملفات PDF السريع** | تحويل صور الشيتات والملاحظات المرسلة للبوت إلى ملف PDF واحد جاهز للرفع والتشارك |
| 2 | **أجندة الدفعة** | جدول زمني مجمع ومنظم لكل مواعيد السكاشن، الكويزات، التسليمات، والاختبارات — للدفعة كلها في مكان واحد |
| 3 | **مكتبة أدوات البرمجة والكلية** | دليل منظم بروابط وشرح لتسطيب البيئات الأساسية (VS Code، Python، Git، إلخ) — موزع على المواد والسنة الدراسية |
| 4 | **دليل الأوريينتيشن للطلبة الجدد** | نصائح وإرشادات شاملة لسنة أولى: أماكن المعامل والمدرجات، مواعيد السكاشن، إزاي تتعامل مع الكلية |
| 5 | **رادار التدريبات والكورسات** | إشعارات دورية بفرص التدريب الصيفي، المنح، وكورسات البرمجة المتاحة — مع روابط التقديم المباشرة |

### 🎮 3. التفاعل والتحفيز (Gamification & Engagement)

| # | الفيتشر | الوصف |
|---|---|---|
| 1 | **نظام تقييم المحتوى** | أزرار تقييم (⭐ مفيد / 👎 محتاج تحسين) أسفل كل ملف أو شرح — يساعد على رفع المحتوى الجيد وتحسين الرديء |
| 2 | **لوحة الشرف (Honor Board)** | ترتيب شهري لأكثر الطلاب تفاعلاً وأكثر المساهمين رفعاً للمحتوى المفيد — منشورة في البوت |
| 3 | **نظام الأوسمة الافتراضية (Badges)** | منح ألقاب ورموز للمتفاعلين بناءً على نشاطهم (`⭐ نجم الدفعة`، `📚 مبدع المحتوى`، `🔥 متحدي اليوم`، إلخ) |
| 4 | **تحدي اليوم** | سؤال أو Quiz سريع يومياً من مواد الكلية لتنشيط الذاكرة — مع عرض نتائج المتحدين في نهاية اليوم |
| 5 | **الأوامر السرية "Easter Eggs"** | ردود مفاجئة ومسلية مخفية تظهر عند كتابة كلمات أو جمل معينة بالصدفة — تضيف طابع شخصية وروح للبوت |

### 👥 4. إدارة تيم ميكروسكوب والـ HR (Team Management)

| # | الفيتشر | الوصف |
|---|---|---|
| 1 | **بوابة الـ HR وإدارة التيم** | قسم سري بكود خاص للإدارة — متابعة حضور الميتينجات، تقييم أداء الممبرز، إدارة اللجان والأدوار الداخلية |

| 3 | **المولّد الآلي لشهادات التقدير** | إصدار شهادات شكر وتقدير للممبرز النشيطين بأسمائهم وتوقيع التيم بصيغة PDF — تُرسل مباشرة للمستخدم عبر البوت |
